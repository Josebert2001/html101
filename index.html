Section 1

HTML Foundations

The vocabulary every page is built from. Get these six words right and 80% of HTML stops looking mysterious.

Anatomy of an HTML element

<a href="about.html">Read more</a>
Opening tag<a> — tells the browser an anchor (link) starts here
Attributehref — extra info this element needs
Value"about.html" — where the link goes
ContentThe text shown to the user
Closing tag</a> — the slash signals the element ends

Section 3

Naming & IDs

How you label elements so CSS (and JavaScript) can find them later. Master this and styling becomes a calm, surgical process.

Section 4

CSS Styling

Now that the structure makes sense, here’s how you make it look good — the rules, the box, the colors, the polish.

Anatomy of a CSS rule

.button { color: white; background: #185FA5; }
Selector.button — which elements to style
Propertycolor, background — what to change
Valuewhite, #185FA5 — what to change it to
DeclarationOne property: value; pair. End each with a semicolon.
