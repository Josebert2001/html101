Core Concepts — tap any card to reveal

HTML

HTML

The skeleton of every webpage — labels content so the browser knows what to display.

HTML stands for HyperText Markup Language. It doesn't make things look beautiful — its job is to label what things are. "This is a heading." "This is a paragraph." "This is an image." The browser reads those labels and lays the page out accordingly. Without HTML, the browser would see nothing but raw unorganized text.
Think of HTML as the rooms of a house — living room, bedroom, kitchen. It defines what each space is for. CSS is the paint and furniture that makes each room look nice.
CSS

CSS

The stylist — makes your HTML beautiful with colors, fonts, and spacing.

CSS stands for Cascading Style Sheets. It is a completely separate file where you write rules like "make this text blue" or "give this card rounded corners." The word cascading means rules flow from general to specific — if all paragraphs are styled red but one specific paragraph is styled blue, the specific one always wins.
If HTML is the skeleton of the human body, CSS is the skin, clothes, hair, and accessories. The bones give structure; CSS gives appearance.
HTML

Tag

A word in angle brackets that labels your content for the browser.

A tag is a keyword wrapped in angle brackets like <p> or <h1>. Most tags come in pairs — an opening tag and a closing tag that has a forward slash. Everything between the two tags is the content being labeled. The browser sees <h1>Hello</h1> and knows to display "Hello" as a big heading.
Like sticky notes on moving boxes — "FRAGILE," "KITCHEN," "BOOKS." The tag labels the content inside so it is handled correctly.
HTML

Element

The complete unit — opening tag + content + closing tag together.

An element is the full complete thing — the opening tag, the content inside, and the closing tag all together. So <p>I love coding.</p> is a paragraph element. Tags by themselves are just labels. Elements are the whole package — the label plus what is being labeled.
A tag is like bread in a sandwich. The element is the complete sandwich — bread, filling, and everything together. The bread alone isn't the meal.
HTML

Attribute

Extra information placed inside an opening tag to describe the element further.

An attribute gives an element extra details it needs to work properly. It lives inside the opening tag and follows the pattern name="value". An image tag needs to know where the image file is — that is the src attribute. The class attribute gives an element a name so CSS can target and style it. Attributes never appear in the closing tag.
Like a name badge at a conference — it gives extra information about the person (name, company, role) without changing who they are fundamentally. The attribute is extra info about the element.
HTML + CSS

Class

A nickname you give elements so CSS knows exactly which ones to style.

A class is a label you attach to an HTML element using class="yourname". You invent the name yourself — it should describe what the element is. Then in your CSS file, you target that class using a dot followed by the name, like .bio { color: gray; }. Multiple elements can share the same class and they will all receive the same styles automatically.
Like a school uniform — every student in Year 3 wears the blue uniform. The class "Year3" is the label; every student with that label gets the same styling.
HTML

<div>

An invisible box that groups elements together so you can style them as one unit.

A <div> is a container element with zero visual appearance on its own. It adds no text, no color, no border — nothing. But it is one of the most important tools in HTML because it lets you wrap related elements together into a group. You then give the div a class and style the entire group with CSS at once. Almost every card, section, and layout box you build will use a div.
Like a cardboard box when packing. The box itself is not the product — but it holds everything together so you can move and organize items as one unit.
CSS

Selector

The part of a CSS rule that points to which element you want to style.

Before you write any CSS styling rules, you must tell the browser which element those rules apply to — that is the selector. Writing .card { ... } means "find every element with the class 'card' and apply these rules to it." A dot selects by class name. No dot selects by tag name — for example, p { color: red; } makes every paragraph red on the page.
Like addressing a letter. The selector is the name on the envelope. Without it, the styles have nowhere to go and nothing gets styled.
CSS

Padding vs Margin

Both create space — but padding is inside the box and margin is outside it.

Padding is space inside a box, between the content and the edge of the box. Making padding bigger makes the box itself larger. Margin is space outside a box, pushing it away from other elements around it. Beginners mix these up constantly — the interactive demo below the cards will make it crystal clear.
Picture a framed photo on a wall. The gap between the photo and its frame is padding. The gap between the frame and the next frame on the wall is margin.
CSS

Hover Effect

CSS rules that activate only when a mouse moves over an element.

The :hover pseudo-class lets you write styles that only apply when a user's mouse is hovering over an element. You attach it directly to any selector: .contact-btn:hover { background: darkblue; }. Nothing happens when the user ignores the button — but the moment their cursor moves over it, CSS activates those rules. This makes interfaces feel interactive and responsive.
Like a touch lamp that glows only when your hand is near it. It is in a resting state normally, but it reacts the moment something comes close.
